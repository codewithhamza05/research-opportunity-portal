# Submission Checklist

Before submitting the assignment:

- [ ] Backend runs successfully
- [ ] MySQL database is created
- [ ] Frontend communicates with backend
- [ ] Create operation works
- [ ] Get all operation works
- [ ] Get one operation works
- [ ] Update operation works
- [ ] Open -> Closed works
- [ ] Delete operation works
- [ ] 404 response tested
- [ ] Validation error tested
- [ ] At least 3 opportunities tested
- [ ] Postman collection exported
- [ ] README contains setup instructions
- [ ] GitHub repository is accessible to instructor
- [ ] No passwords or API keys are committed
- [ ] One-minute demonstration video is recorded
